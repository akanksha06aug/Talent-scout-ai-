# 🤖 Talent Scout AI

Talent Scout AI is a browser-based resume screening and talent discovery application.

## Features

- Upload PDF resumes
- Upload TXT resumes
- Extract resume text
- Match resume skills with required skills
- Calculate skill match percentage
- Detect missing skills
- Check resume completeness
- Identify possible resume quality issues
- Talent Quest mini challenges
- Responsive design
- Works with GitHub Pages

## Technologies

- HTML
- CSS
- JavaScript
- PDF.js

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a browser.

## GitHub Pages

Go to:

Settings → Pages

Select:

Branch: `main`

Folder: `/ (root)`

Click Save.

GitHub will generate your website URL.

## Disclaimer

This project provides basic rule-based resume analysis for educational purposes. It does not determine whether a resume or candidate is genuinely qualified, and its results should not be treated as a hiring decision.
